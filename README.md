# Tenz (Fabric, MC 26.3)
- Right Shift: Tenz menu. K: auction menu (pick an item, amount, time). Both rebindable in Controls > Tenz.
- Themes: Tenz menu > Appearance (Frost, Purple, Ocean, Rose, Emerald, Sunset, Midnight).
- `/tenz auction 60 Elytra x1` starts an auction; `/tenz bid Name 12500000` places a bid.
- Push to GitHub, Actions builds, download the jar from the run's Artifacts.
- Fun tab: alien skins + payment animations (master switch plus one toggle each). O opens the top donators board.
- Payments trigger from chat lines like "Name paid you $10M", `/tenz pay Name 250M`, or `/tenz demo` (plays every animation).
- `/tenz dump` writes tenz-api-dump.txt (in the game folder) with the real 26.3 sky and player-model classes.
